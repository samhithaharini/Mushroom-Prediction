## **Mushroom Classification Using Naive Bayes**

A Machine Learning project to predict whether a mushroom is edible or poisonous using the Naive Bayes Classification Algorithm.

---
**Project Overview**

This project applies Gaussian / Multinomial Naive Bayes to classify mushrooms based on their physical and chemical features.
The goal is to build a predictive model that can accurately determine mushroom safety based on given characteristics.

---

Algorithm Used: Naive Bayes Classifier

Why Naive Bayes?

Works extremely well for categorical data

Fast, simple, efficient

Performs well even with high-dimensional features

Ideal for mushroom dataset where attributes are independent
